# OTF-MLFF-Tg
Data for "On-the-Fly Machine-Learned Force Fields for High-Fidelity Polymer Glass Transition Simulations".

This folder contains the initial structure for building a machine-learning force field for the respective polymers.

POSCAR: Initial structure

CONTCAR: Equilibrated structure after 200ps run (step size 0.4 fs).

CONTCARs were further used to build larger polymeric structures containing multiple chains for performing Tg-simulation.

Each folder also contains the respective larger polymeric structure "POSCAR-ss", which is used as an starting structure for perfroming Tg-simulations. The protocol followed is mentioned in the manuscript and SI.
